# 报告输出契约

评测的价值在可对比。本页锁定三样东西：回执格式、横比表列定义、口径声明。
脚本产出的 jsonl/json 是原始数据；本页是把数据写成报告时的固定格式。

## 完成回执（每轮评测结束必给）

```markdown
| 技能 | 当前状态 | 当前版本 | 最新版本 | 运行状态 | 更新时间 | 处理结果 |
|---|---|---|---|---|---|---|
| 环境检查 | <已检查/被阻塞> | <引擎名+版本> | 不适用 | <正常/降级/异常> | <RFC3339-with-timezone> | <可继续/缺口> |
| 题库评测 | <已完成/部分完成> | <模型标识> | 不适用 | <正常/异常> | <RFC3339-with-timezone> | <PASS x / FAIL y / 待人工 z / skipped n> |
| 吞吐专项 | <已完成/跳过> | <模型标识> | 不适用 | <正常/异常> | <RFC3339-with-timezone> | <聚合峰值 tok/s @并发 n> |
| Agent 集成 | <已完成/跳过> | <agent 名单> | 不适用 | <正常/异常> | <RFC3339-with-timezone> | <PASS/FAIL 摘要> |
```

- skipped 项逐条列出原因（如 A2/A4 未配置 context_file）。
- 数字必须来自本轮结果文件，注明 group 标签与配置（量化位宽、推理深度、prompt 长度）。
- 只为实际执行过的阶段输出行；`更新时间` 记该行最后一次形成结论的时间（RFC 3339 含时区），
  不用技能源码的 frontmatter 时间。

## 横比表列定义（跨模型对比的固定列）

测完新模型在总览表加一列，行定义不变：

| 行 | 定义 |
|---|---|
| 引擎 | mlx-lm / llama.cpp / 其他 |
| 判别集（n 题） | 自动判定题全对与否，写 `x/n`；n 随题库版本走 |
| decode tok/s | 单流生成速度（题库 A 类计时结果区间） |
| 并发聚合峰值 | throughput 结果中最大聚合 tok/s（注明并发级别） |
| 长 prompt prefill | A2/6k prompt 的 prefill 吞吐（未配置则记「未测」） |
| 内存 RSS | hw_summary 的 RSS 峰值 |
| GPU/CPU 活跃 | hw_summary 的活跃均值 |
| 加载 冷/热 | 首次加载耗时 / 热启动耗时 |
| 必要配置 | 不配就不可用的开关（如必须关思考，否则零输出） |

## 统计资格（质量差异结论的前提）

1. 17 题量级下 ±1-2 题的差异默认是噪声，禁止表述为「A 略优于 B」——配对比较要
   ≥6 题单向翻转才可能达到 p<0.05。
2. 声称两组配置存在质量差异，必须先跑 `python3 scripts/flip_report.py <workdir> <groupA> <groupB>`，
   并在报告中给出翻转数（regression/improvement 题号清单）与双侧精确 McNemar p 值。
3. 样本量或翻转数不足时的唯一合法表述是「本轮未观察到有统计资格的差异」，
   不可分辨就写不可分辨。

## 口径声明模板（对外分享数字前必附）

```text
口径：速度为端到端 HTTP（含调度/Tokenizer/Prefill/逐 token 解码）；
并发聚合 = 批次全部请求 completion_tokens 之和 / 批次墙钟；
TTFT 区分冷/热（服务器 prompt cache 命中与否，缓存命中率本轮<已/未>采集）；
测速时后台无重 IO。配置：<量化位宽 / 推理深度档 / 上下文窗口 / decode 并发>。
```

与他人数字对比前先对口径——聚合算法、是否含 prefill、缓存冷热任何一项不一致，
数字都不可直接比。

投机解码（MTP / draft 模型）配置另加一条硬规则：速度必须按**语言 x 任务四象限**
（英文生成 / 英文编辑 / 中文生成 / 中文任务）分别报 tok/s——draft 接受率随目标语言
token 分布剧烈变化，单一英文数字会把中文日常体验高估 2 倍以上（实测同一配置英文
38.5-53.0 tok/s、中文 chat 任务仅 14-24 tok/s，数据见 methodology.md）。
采纳决策以目标语言的数字为准。

## 产物落点

| 产物 | 落点 | 说明 |
|---|---|---|
| 原始数据 | `<workdir>/results/` 与 `<workdir>/outputs/` | 机器本地，不进知识库、不上传 |
| 单模型纵比 | 用户知识库的「<模型名>-测试档案」笔记 | 配置矩阵、硬件画像、踩坑，附数据与日期 |
| 跨模型横比 | 用户知识库的模型对比总览表 | 测完新模型加一列，只维护一张表 |
| 对外分享报告 | Artifact（可选） | 含口径声明；不含私有题面与业务代码 |

落点属于用户资产：写入前确认目标笔记存在并征得同意，没有知识库的用户只交付本地
results 文件与聊天内回执。
